❓ FREQUENTLY ASKED QUESTIONS
═════════════════════════════════════════════════════════════════════════════════

Q: How long does deployment take?
A: 20-30 minutes total if all services first-time setup. Vercel + Azure auto-deploy 
   so minimal waiting needed.

Q: What if deployment fails?
A: Check:
   1. MongoDB connection string format (copy-paste carefully)
   2. .env variables spelling in Azure (case-sensitive)
   3. GitHub token for Vercel (if using Git auto-deploy)
   4. Network access on MongoDB Atlas (should be 0.0.0.0/0 for now)

Q: Can I test locally first?
A: Yes! Run: npm run dev (in backend folder)
   Then: npm start (in frontend-admin folder)
   Hits http://localhost:3000 and http://localhost:3001

Q: How do I seed the 10 free icons?
A: Two options:
   1. Run testMarvelMint.ts (creates sample icons)
   2. Manually insert via MongoDB Atlas dashboard (choose seedBasicIcons.ts data)

Q: What's the session timeout?
A: 30 minutes exactly. After that, login again.
   No "Remember me" option (security hardened).

Q: Can multiple admins login?
A: Yes! Add more admin users by adding new entries in adminAuthService.ts
   Each gets their own password (bcryptjs hashed).

Q: What happens if login fails?
A: Backend returns 401 Unauthorized.
   Frontend shows error message.
   After 3 failed attempts, recommend 5-minute wait (anti-brute-force).

Q: How do I disable an admin account?
A: Backend only accepts users in hardcoded list.
   To disable: Remove from adminAuthService.ts and redeploy.

SOLUTION:
  • Backend API not responding → check Azure deployment
  • Check browser console (F12) for JavaScript errors
  • Verify REACT_APP_API_BASE env var is set correctly

SOLUTION:
  • Image URLs must be accessible from browser
  • Check CORS headers (backend should allow Vercel origin)

  • Fallback: Use placeholder image if upload fails

  • Check market_assets collection has 10 documents
  • Verify each has: collection="basics_free", is_default=true, rarity="gratis"
