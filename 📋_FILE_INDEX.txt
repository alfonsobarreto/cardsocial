📱 MOBILE APP INTEGRATION
═════════════════════════════════════════════════════════════════════════════════

How Mobile App Uses This
────────────────────────────────────────────────────────────────────────────────

ON USER REGISTRATION:
  1. Mobile completes registration form
  2. Backend creates user in auth database
  3. Backend calls: marketSyncService.initializeNewUserVault(uid)
  4. Service loads 10 free icons from market_assets
  5. Creates user_vaults document with free icons
  6. Mobile displays vault with icons ready-to-use ✅

ON USER OPENS MYCARD:
  1. Mobile queries: GET /api/sync/skins/:uid
  2. Backend returns all user-owned skins
  3. Mobile renders skin selector in MyCard editor
  4. User can apply skin to their card

WHEN ADMIN PUBLISHES NEW ASSET:
  1. Admin clicks "Publish" on dashboard
  2. Backend updates market_assets: status = "published"
  3. Backend calls: notifyAllUsersNewAsset(asset_id)
  4. Service marks all user_vaults: needs_sync = true
  5. Mobile app polls GET /api/sync/stats
  6. Detects needs_sync flag
  7. Calls: POST /api/sync/vault/:uid to pull new asset ✅

LATENCY GUARANTEE:
  • User sync happens on next app foreground (0-5 seconds)
  • Or: On-demand call takes <2 seconds
  • Fallback: Local cache if network fails
